# Evals

Track proof that the agents save time and money.

For each agent, record:
1. **Manual baseline:** how long a PM takes to do the task by hand (time it once).
2. **Agent run:** time, tokens, cost from the run metrics footer.
3. **Quality check:** human review of a sample (are themes accurate, evidence cited, nothing invented?).

Log results in `results.csv` and copy the summary into the main README table.
